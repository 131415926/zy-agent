# 阶段①：ChatModel、消息与提示词

对应示例：`tutorials/01_chat_basics.py`、`tutorials/02_prompt_templates.py`、`tutorials/03_output_structured.py`

## 1. ChatModel 基本调用

1.x 中统一使用 ChatModel（旧的 `LLM` 补全接口已边缘化）：

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
# 兼容 OpenAI 协议的第三方：ChatOpenAI(base_url=..., api_key=..., model=...)

resp = llm.invoke("用一句话介绍 LangChain")   # -> AIMessage
print(resp.content)
```

三个统一方法（所有 ChatModel 都有）：

| 方法 | 返回 | 用途 |
|---|---|---|
| `invoke(x)` | 单条消息 | 一次完整调用 |
| `stream(x)` | 迭代 AIMessageChunk | 流式输出 |
| `batch([...])` | 列表 | 并发批量 |

## 2. 消息类型

```python
from langchain_core.messages import SystemMessage, HumanMessage, AIMessage

msgs = [
    SystemMessage(content="你是一个简洁的翻译助手"),
    HumanMessage(content="翻译：hello world"),
]
resp = llm.invoke(msgs)
```

- `HumanMessage` / `AIMessage` / `SystemMessage` / `ToolMessage`
- 多轮对话 = 把历史消息按顺序放进列表再 invoke（配合 LangGraph checkpointer 可自动管理）

## 3. 提示词模板

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是{domain}领域的专家，回答保持{style}。"),
    ("human", "{question}"),
])

chain = prompt | llm          # LCEL 管道
resp = chain.invoke({"domain": "数据库", "style": "简短", "question": "什么是索引？"})
```

要点：
- `prompt | llm | parser` 是 LCEL（LangChain Expression Language），整条链支持
  `.invoke / .stream / .batch`，与单个模型一致。
- 常用 parser：`StrOutputParser()`（取 `.content` 字符串）。

## 4. 结构化输出（重点）

```python
from pydantic import BaseModel

class BookReview(BaseModel):
    title: str
    score: int          # 0-10
    summary: str

structured_llm = llm.with_structured_output(BookReview)
review: BookReview = structured_llm.invoke("评价一下《三体》")
print(review.score)
```

底层自动走 OpenAI 的 tool-calling / JSON schema，返回直接是 Pydantic 对象，
是做抽取、分类、打分类任务的首选。
