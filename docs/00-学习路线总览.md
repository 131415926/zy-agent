## 1.x 版本要点（与旧版教程最大的差异）

1. **`create_agent` 是新入口**：`from langchain.agents import create_agent`，
   参数为 `(model, tools, system_prompt, middleware, checkpointer, ...)`。
   旧版 `AgentExecutor` / `initialize_agent` 已淘汰，不要再学。
2. **langgraph 取代 LangChain 内部 Agent 循环**：`create_agent` 底层就是一张
   LangGraph 图；掌握 LangGraph = 掌握自定义 Agent 的钥匙。
3. **多轮记忆**：1.x 用 `checkpointer`（如 `InMemorySaver`）+ `thread_id`
   实现会话持久化，而不是旧的 `ConversationBufferMemory`。
4. **LCEL 链（`|` 管道）仍然核心**：`prompt | model | parser`。
5. **包拆分**：核心在 `langchain-core`，OpenAI 在 `langchain-openai`，
   第三方集成在 `langchain-community`。

## 运行准备

```bash
conda activate langchain

# 配置模型 API（任选其一，写入 agent-app/.env 或直接 export）
export OPENAI_API_KEY=sk-xxx
# 或兼容 OpenAI 协议的国产模型：
export OPENAI_API_BASE=https://your-endpoint/v1
export OPENAI_MODEL=your-model-name

# 跑示例（不需要 key 的：02/04/07 的部分环节）
python tutorials/01_chat_basics.py
```

没有 API key 也能学习：示例中凡涉及真实调用的地方都标注了
`# 需要 API key`，先读代码理解结构即可；实战项目支持
`--dry-run`（不调模型，验证链路）。
